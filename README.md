# Dnevchik — Личный дневник

Настольное приложение для ведения личного дневника. Работает локально — все записи хранятся на твоём компьютере в виде `.md` файлов.

## Возможности

- **Редактор** — rich-текст с форматированием, шаблонами, тегами, настроением, медиафайлами и режимом фокуса
- **Хроника** — записи на временной шкале, сгруппированные по датам
- **Поиск** — полнотекстовый поиск с фильтрами по тегам, настроению и избранному
- **Граф связей** — Obsidian-like визуализация связей между записями через `[[ссылки]]`
- **Статистика** — график настроения, тепловая карта активности, облако слов
- **Привычки** — еженедельный трекер с серией дней
- **5 тем** — тёмная, светлая, монохром, сепия, терминал
- **PIN-защита** — блокировка при запуске
- **Погода** — автоматически определяется по геолокации
- **Тональность** — анализ настроения текста по русскому словарю
- **История версий** — снапшоты записей каждые 5 минут
- **Wiki-ссылки** — `[[название записи]]` создаёт двусторонние связи между записями

## Стек

| Часть | Технологии |
|-------|-----------|
| Frontend | React 19 + TypeScript + Vite |
| Desktop | Tauri 2 (Rust + WebView2) |
| Редактор | Tiptap (ProseMirror) |
| Анимации | Framer Motion |
| Иконки | Lucide React |
| Хранилище | `.md` файлы через Tauri FS API |

## Требования

- **Windows 10/11** (64-bit)
- [Node.js 18+](https://nodejs.org/)
- [Rust](https://rustup.rs/) (для сборки)
- [WebView2 Runtime](https://developer.microsoft.com/ru-ru/microsoft-edge/webview2/) — обычно уже установлен на Windows 11

## Установка и запуск

### Быстрый запуск (dev-режим)

```powershell
# 1. Клонировать репозиторий
git clone https://github.com/gumi4689/dnevchik.git
cd dnevchik

# 2. Установить зависимости
npm install

# 3. Запустить через bat-файл
start.bat
```

Или вручную:

```powershell
# Запустить Vite dev-сервер
npx vite --host 127.0.0.1 --port 5175

# В отдельном окне — запустить приложение
.\src-tauri\target\debug\dnevchik.exe
```

### Полная сборка

```powershell
npm run tauri build
```

Собранный установщик появится в `src-tauri/target/release/bundle/`.

## Данные

Записи хранятся в `%APPDATA%\Dnevchik\` в виде `.md` файлов с YAML frontmatter:

```markdown
---
id: "uuid"
title: "Название записи"
mood: 7
tags: ["мысли", "день"]
createdAt: "2026-05-12T10:00:00.000Z"
---

Текст записи...
```

Путь к папке можно изменить в **Настройки → Хранилище**.

## Wiki-ссылки

Пиши `[[Название другой записи]]` в тексте — приложение автоматически покажет:
- **Исходящие ссылки** — записи, на которые ссылается текущая
- **Обратные ссылки** — записи, которые ссылаются на текущую
