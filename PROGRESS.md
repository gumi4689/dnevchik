# Dnevchik — История разработки

## Стек
- **Frontend**: React 19 + TypeScript + Vite 8 (порт 5175)
- **Backend**: Tauri 2 (Rust), WebView2 на Windows
- **Стили**: CSS Modules + CSS Variables, 5 тем
- **Анимации**: Framer Motion
- **Хранение**: файлы `.md` в папке данных (`%APPDATA%\Dnevchik` → реальный путь)
- **Настройки**: localStorage

---

## Реализованные фичи

### Базовый функционал
- Создание, редактирование, автосохранение записей (через 1.5с после изменений)
- Rich-текстовый редактор (RichEditor на базе ProseMirror/Tiptap)
- Файловое хранилище: каждая запись → `{id}.md` с YAML frontmatter
- Миграция из localStorage в файлы при первом запуске
- Онбординг (3 шага с именем, возрастом, выбором папки)
- Кнопка «Назад» на всех шагах онбординга

### Навигация
- Боковая панель (SideNav) с изменяемой шириной (drag-resize)
- Позиция сайдбара: слева / справа
- Вкладки с группировкой (TabBar): создание групп, переименование, цвет
- Виджеты в сайдбаре: настроение, статистика, серия дней, мини-календарь

### Страницы
| Страница | Описание |
|----------|----------|
| **Главная** | Приветствие, статистика, список последних записей, промпт дня, ретроспектива год назад |
| **Запись** | Редактор с шаблонами, тегами, настроением, медиафайлами, режимом фокуса |
| **Хроника** | Timeline — записи сгруппированы по датам, цветная полоска настроения |
| **Календарь** | Сетка месяца с точками активности, просмотр записей по дням |
| **Поиск** | Полнотекстовый поиск + фильтр по тегам + фильтр по настроению + избранное |
| **Статистика** | Сводные карточки, график настроения 30 дней, тепловая карта 84 дня, облако слов, граф |
| **Граф** | Obsidian-like граф связей через теги, pan/zoom, анимированная физика |
| **Настроение** | Отдельная страница выбора настроения |
| **Привычки** | Еженедельный трекер привычек, серии, навигация по неделям |
| **Настройки** | Оформление, текст, редактор, интерфейс, напоминания, безопасность, хранилище |

### Темы оформления
- `dark` — Obsidian (по умолчанию, фиолетовый акцент)
- `light` — Светлая
- `bw` — Монохром
- `warm` — Сепия
- `green` — Терминал

### Настройки (AppSettings)
```typescript
theme, fontSize, editorFont, spellCheck, compactMode,
showWordCount, showMoodOnHome, activeWidgets,
dataDir, sidebarPosition, sidebarWidth,
customFontName, customFontData,   // кастомный шрифт из файла
accentColor,                       // переопределяет цвет акцента темы
editorTexture,                     // none | lines | grid | dots
reminderEnabled, reminderTime      // ежедневное браузерное уведомление
```

### Редактор (NewEntryPage) — дополнительные фичи
- **Шаблоны** — при создании новой записи: 8 шаблонов (утренние страницы, рефлексия, цели недели, благодарность, анализ решения, письмо себе, обзор месяца, свободная запись)
- **Режим фокуса** — скрывает шапку, `Alt+F` или кнопка, выход по `Esc`
- **Погода** — автоматически через geolocation + Open-Meteo API (бесплатно), отображается в шапке
- **Тональность** — полоска под редактором: подсчёт позитивных/негативных русских слов из встроенного словаря
- **Wiki-ссылки** — пишешь `[[название записи]]` → ниже появляются связанные записи
- **История версий** — каждые 5 минут сохраняет снапшот (до 5 версий), кнопка в шапке
- **Закладки** — звёздочка в шапке, отмечает запись как избранную
- **Прогресс прокрутки** — тонкая полоска справа
- **Цвет шапки** — тонтированный фон в зависимости от выбранного настроения
- **Кастомный курсор** — в зоне редактора

### Безопасность
- **PIN-код** — 4-цифровая защита. Экран блокировки при запуске, цифровая клавиатура, анимация тряски при неверном вводе
- Установка/изменение/снятие PIN в настройках

### Ежедневные подсказки (60 вопросов)
- Появляются на главной если нет записи сегодня
- «Написать об этом» → открывает редактор с вопросом как начальный текст
- Кнопка обновить → следующий вопрос

### Граф (GraphWidget / GraphPage)
- Физическая симуляция (force-directed, requestAnimationFrame)
- Узлы связаны общими тегами
- Размер узла = количество связей
- Цвет узла = настроение записи
- Pan (перетаскивание), Zoom (колёсико мыши)
- SVG glow-фильтры, анимированное оседание
- ResizeObserver — адаптируется к любому размеру контейнера

### Трекер привычек (HabitsPage)
- Добавление привычек с emoji и цветом
- Сетка 7 дней × N привычек
- Отметка выполнения
- Счётчик серии (streak)
- Навигация по неделям

### Облако слов (WordCloud в StatsPage)
- Canvas-based рендер без внешних зависимостей
- Топ-60 слов из всех записей
- Исключает стоп-слова (союзы, местоимения)
- Размер слова = частота

### Обложка при запуске (AppCover)
- Анимированный экран 1.6с при каждом запуске
- Иконка книги + название + текущая дата
- Плавное исчезновение

## Запуск (dev)

```powershell
# Остановить старые процессы
Get-Process -Name "node","dnevchik" -ErrorAction SilentlyContinue | Stop-Process -Force

# Запустить Vite dev сервер
Start-Process "cmd" -ArgumentList "/c cd E:\proekts\Dnevchik && npx vite --host 127.0.0.1 --port 5175"

# Подождать 7 секунд, затем запустить exe
Start-Sleep 7
Start-Process "E:\proekts\Dnevchik\src-tauri\target\debug\dnevchik.exe"
```

> Для перекомпиляции Rust (если менялся `src-tauri/`): `npm run tauri dev` в папке проекта.

## Известные особенности

- Данные хранятся по пути из настроек (`dataDir`). `%APPDATA%\Dnevchik` резолвится в реальный путь при первом запуске через `appDataDir()` из `@tauri-apps/api/path`.
- Кастомный шрифт хранится в `localStorage` отдельно от настроек (base64 может быть большим).
- История версий записей хранится внутри самого Entry объекта (до 5 снапшотов).
- Привычки хранятся в `localStorage` (`dnevchik_habits`, `dnevchik_habit_logs`).
- Погода кешируется в `sessionStorage` на 30 минут.
- PIN хранится в `localStorage` открытым текстом (защита от случайного просмотра, не от взлома).
